# Lab 2: Epics and User Stories

Agile requirements for the **Personalized Meal & Diet Subscription Manager**, written as epics with user stories in "As a / I want to / So that" tables.

## What I did

Defined five epics and broke each into user stories:

| Epic | Focus |
|------|-------|
| 1. Subscriber Health Profile & Metric Tracking | Metabolic profile, daily vitals logging, encryption and role-based access |
| 2. Automated Meal Plan Generation & Allergen Validation | 7-day plans within 5% of calorie goal, automatic allergen filtering, 2.5 s generation target |
| 3. Clinical Review & Dietitian Approval Workflow | Dietitian inspection, overrides and sign-off before dispatch |
| 4. Delivery Schedule Management | Pause, skip or reschedule, with a 12-hour cutoff |
| 5. Order Fulfillment & Delivery Tracking | Real-time delivery status and instant notifications |

The stories include non-functional needs (AES-256 at rest, TLS 1.3, RBAC, performance targets) written as stories for the Sys Admin, Sys Engine and Platform Architect roles.
